# GroupC

This directory contains `frontend_v2` — the frontend for **Mapper**, a Safe Route
Navigation System for South African drivers.

**Full documentation, setup instructions, and architecture overview live in the primary
README**: [`../map-app-render-deployment/README.md`](../map-app-render-deployment/README.md).

The backend this frontend talks to is `../map-app-render-deployment/backend` —
**`GroupC/backend_v2` is dead/legacy code, not used anywhere, and should be ignored.**
